청중·시간: $ARGUMENTS (기본: 포트폴리오 설명 5분)

근거: `INTENT.md` 핵심 시나리오, `planning.md` 완료 기준, `audit/BASELINE-after.md`(있으면), `decisions/` 핵심 결정.

`docs/demo-script.md` 에 쓴다.
1. **사전 준비 체크리스트** — 데모 계정(실계정 정보는 문서에 쓰지 않는다), 시드 데이터, 로컬/운영 중 무엇으로 할지, 네트워크 없을 때 대비, 브라우저 탭 순서
2. **시연 순서** — 시간 배분, 화면별 한 줄 멘트. 핵심: 링크 붙여 넣기 → 자동 채움 → 공유 링크 → 메신저 미리보기 → (선택) 키보드 순서 변경·에러 화면
3. **보여줄 설계 포인트** — 결정 2~3개와 전후 수치
4. **플랜 B** — 외부 사이트 메타데이터 추출 실패, 로그인 실패, 네트워크 장애 시 대체 화면·녹화본
5. **예상 질문과 답**
