# worklog — "오늘 무엇을 했나"

## 규칙

- 날짜별 파일 `YYYY-MM-DD.md` (날짜는 `date +%Y-%m-%d` 로 확인)
- 같은 날 여러 번 기록하면 파일 끝에 `---` 로 구분해 이어 붙인다
- 항목 구성: **참여 에이전트 / 논의 내용(누가 어떤 의견) / 결론·결정 / 미결·다음**
- 결정의 맥락은 `decisions/`, 확정 목록은 `planning.md`, 다음 작업은 `todo/` 에 쓰고 여기서는 링크만 한다
- `/log` 커맨드(7단계에서 생성)가 이 파일을 갱신한다. 그 전에는 직접 기록한다
- 세션 끝에는 반드시 기록한다

`2026-09-27.md` 는 리뉴얼 0~5단계 기록으로, `/log` 도입 전 형식(완료 / 결정 / 미결 / 다음)을 쓴다.
