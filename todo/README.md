# todo — "누가 다음에 무엇을 하나"

## 규칙

- 전체 계획: `mvp-todo.md` (Phase 단위, 9단계 로드맵에서 작성)
- 역할별: `{역할}-todo.md` (7단계에서 만든 에이전트마다 하나)
- 나중에 할 것: `someday.md` (이번 리뉴얼 범위 밖)
- 각 항목은 **커밋 하나로 끝날 크기**로 쪼갠다. 항목마다 아래를 함께 적는다
  - 완료 조건
  - 예정 커밋 메시지 — `커밋: type(scope): subject`
  - 관련 `audit/FEATURES.md` ID
- 완료하면 체크하고 날짜·커밋 해시를 적는다: `- [x] ... (2026-10-01, a1b2c3d)`
- 직접 작성할 모듈은 "담당: 에디"로 표시한다 (현재 없음)
- 작업 중 발견한 계획 밖 문제(버그·부채)는 고치지 말고 해당 todo에 추가하고 보고한다
