이 화면에서 지킨 것 · 메모

  • 한 화면에 한 가지 일: 랜딩·로그인 모두 강조색 버튼 하나
  • 말하듯 쉬운 문구: "붙여 넣어요 / 모여요 / 보여줘요", 버튼은 결과 동사
  • 온도감(design-direction 조건 2): 기울인 예시 카드와 친근한 문구로 B의 차가움을 보완. 일러스트는 넣지 않고 실제 UI 조각을 예시로 쓴다
  • 예시 위시리스트 보기 = 공개 데모 공유 페이지로 이동(로그인 불필요)
  • 비목표: 익명 위시리스트 없음 → 랜딩에서 바로 입력하는 UI를 두지 않는다
