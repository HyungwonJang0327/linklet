공유 링크 + 메신저 미리보기 모습. 주된 행동 "링크 복사하기", 보조로 꾸미기·더 담기. 복사 직후 토스트. "외 N개"는 N>0일 때만, 링크를 건너뛴 경우(아이템 0)는 카드 대신 "첫 아이템을 담으면 미리보기에 사진이 나와요" 문구.

이 화면에서 지킨 것 · 메모

  • 단계형 입력 + 기본값: 이름(필수) → 링크(선택) → 완성. 질문 2개로 3분 안에 끝난다
  • 기본 공개(F15) 문구: "링크를 아는 사람만 볼 수 있어요" — "공개"라는 단어 대신 실제 의미를 말한다
  • 공유 받는 사람도 사용자: 3/3에서 메신저 카드가 어떻게 보일지 미리 보여 준다(완료 기준 2)
  • 제출 중 중복 실행 방지: 버튼 aria-busy + 비활성 (구현 메모)
  • 데스크톱은 같은 단계를 가운데 560px 열로 — 별도 시안 없음
