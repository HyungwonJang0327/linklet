# design — UI 리디자인 시안

> 결정 맥락: `decisions/roadmap.md` (UX 원칙 12개, 리디자인 단계). 선택 결과는 `decisions/design-direction.md`, 토큰은 `decisions/design-tokens.md`.

## 보는 법

`design/mockups/*.html` 을 브라우저에서 바로 연다 (빌드·서버·외부 스크립트 없음, 폰트도 시스템 폰트만).

```bash
open design/mockups/direction-a.html   # macOS
```

- 파일마다 오른쪽 위 **"다크 보기"** 토글로 다크 토큰을 확인한다 — 마크업은 그대로 두고 CSS 변수 값만 바뀐다 (F29 의 구현 방식과 같다)
- 색·간격·반경·타이포는 전부 파일 상단 `.theme { --c-* / --r-* / --t-* }` 변수(토큰 후보)로만 쓴다. 원색 값을 본문 스타일에 직접 쓰지 않는다
- 화면 안의 상품 이미지는 CSS 그라디언트 자리표시자다

## Phase 0 — 시각 방향 후보 (2026-11-08)

같은 화면 2개(공유 페이지 `/w/{shareId}`, 내 위시리스트 목록 `/ko/wishlists`)를 세 방향으로 만들었다. 세 안 모두 UX 원칙을 같은 방식으로 지키고 **시각 무드(색·타이포·밀도)만 다르다**.

|---|---|---|---|---|---|
| `mockups/direction-a.html` | A 따뜻한 종이 | 종이 위 스크랩북, 잡지처럼 한 장씩 | 미색 `#F7F3EC` · 잉크 `#2B2521` · 테라코타 `#B5472F` | 제목 26/600, 본문 15, 반경 20 | 낮음 — 공유 1열, 목록 가로형 카드 |

### 세 안에 공통으로 넣은 UX 원칙 (`decisions/roadmap.md`)

- 한 화면 한 가지 일 — 목록의 강조색 버튼은 "새 위시리스트 만들기" 하나. 공유 페이지는 둘러보기만
- 콘텐츠가 주인공 — 상품 이미지 영역에 장식 없음, 카드 테두리 최소
- 말하듯 쉬운 문구 — "상품 보러 가기", "나도 만들어 보기", "받았어요"
- 모바일 우선 — 390px 기준으로 먼저 그리고 데스크톱은 그 확장. 주요 버튼은 하단 고정(엄지 영역)
- 공유 받는 사람도 사용자 — 공유 페이지는 로그인 요소 없이 소유자·제목·아이템만, 하단에 작은 유입 동선
- 접근성 기준선 — 카드 전체가 `<a>`, 아이콘 버튼 `aria-label`, `:focus-visible` 링, 본문·보조 텍스트·강조 버튼 대비 4.5:1 이상(라이트·다크 모두 계산 확인), `prefers-reduced-motion` 존중
